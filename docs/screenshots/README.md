# Screenshots

Each image comes in light and dark, and the README picks the one that matches
GitHub's theme.

## The images

| Image | Shows |
| --- | --- |
| `repos` | the four bars in the menu bar, Repos open: every repository with its branch and markers |
| `branches` | a repository's local branches with their tracking, one checked out in a worktree |
| `diverged` | a repository behind and ahead at once: the commit to pull and the commands that fix it |
| `stashes` | a repository with stashes: each one, its branches and the actions on it |
| `devports` | the services holding a port, named after their project, one opened with what it costs |
| `colima` | the VM and its containers, one opened |
| `llama` | the loaded model and the context window it is using |
